# Codebreakers Consultancy website

This is the editable static website for Codebreakers Consultancy.

## Main files

- `index.html` — Home page
- `about/index.html` — About page
- `appointments/index.html` — Appointments and booking page
- `styles.css` — All website styling, including mobile layout
- `script.js` — Mobile navigation behaviour
- `favicon.svg` — Website icon
- `forms/README.md` — Information about the current booking form

## Open in VS Code

1. Extract this folder completely — do not edit the files while they are still inside the `.zip` file.
2. Open the extracted folder in VS Code.
3. Open `index.html` with the Live Server extension, or open it directly in a browser. The project uses relative file paths, so the CSS and JavaScript also work when opened locally.
4. Edit `styles.css` for colours, spacing and layout.
5. Edit the HTML pages for wording and page content.

The website uses the Microsoft 365 address `Jo@CodebreakersConsultancy.onmicrosoft.com` as a mail link. Replace it later if you create a custom business email domain.
